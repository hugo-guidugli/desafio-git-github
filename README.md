### 📌 Conteúdo Resumido do Guia:
* **Problema x Solução:** A transição das cópias `.zip` para o versionamento distribuído.
* **Matriz de Diagnóstico:** Diferenças operacionais entre o Git (engine local) e o GitHub (nuvem/colaboração).
* **Dicionário de Comandos:** `git init`, `git clone`, `git status`, `git add`, `git commit`, `git push`, `git pull`.
* **Estratégia de Branches & GitHub Flow:** Isolamento de *features*, resolução de conflitos e revisão via Pull Requests.
* **Documentação & Portfólio:** Boas práticas de escrita para o `README.md` e apresentação de projetos.
* **Inteligência Artificial:** Uso do GitHub Copilot para otimização de testes, refatoração de código e aumento de produtividade.
